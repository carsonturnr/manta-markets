# 2026-11-22 relay

## What
- `recorder/internal/relay`: keeps each Kalshi market's book and latest 20 trades in memory from the recorder's own writes (`rawlog.Writer.OnWrite`, through `internal/normalize`), and pushes changes over Server-Sent Events, at most once per market every 250 ms.
- Served by the recorder over TLS on :8791 (`-relay-addr`; certificate and key in /etc/manta/relay.*). Bearer `RELAY_TOKEN`, GET only: `/stream?tickers=A,B` (≤ 50 tickers, ≤ 100 streams) and `/health`.
- Message: one `data:` line per changed market, its whole state: `{"ticker","live","t" (unix ms),"bids":[[px,sz]…],"asks":[[px,sz]…],"trades":[{"t","side","px","sz"}…]}`; dollars and contracts, YES side, best first, trades newest first. `live:false`: the book may have missed an update, no levels until Kalshi's next snapshot.
- `deploy.sh` keeps the binaries other scripts installed, makes the relay token and certificate once, opens 8791. Deployed 2026-11-22 22:45 UTC (Carson's go-ahead); RELAY_URL, RELAY_TOKEN, RELAY_CA set in Vercel (Production).

## Why
Step 12: the terminal's books and trades update live instead of being polled every 2 s.

## Decisions
- SSE over WebSockets: one-way data, plain HTTP a Next route can pipe through, automatic reconnect, standard library only.
- Inside the recorder: the records are already in memory; the hook never blocks, and a relay problem turns the relay off, never the recording.
- Whole state per push: the client replaces what it had; a missed push is harmless.
- TLS with a pinned self-signed certificate: no DNS change or new VM package, stricter than trusting public authorities.
- Cost: 6.5 µs a record on series-1, about 4.7% of a core at the busiest hour; +30 MB memory (docs/decisions.md).

## Site contract (terminal worktree)
`app/api/live/stream/route.ts`: validate tickers, request `${RELAY_URL}/stream?tickers=…` with `node:https` and `{ca: RELAY_CA, headers: {authorization: "Bearer " + RELAY_TOKEN}}` (global fetch can't take `ca` without undici), return the body as `text/event-stream`. `Live.tsx`: `EventSource` for Kalshi; `/api/live` polling stays for Polymarket and while `live` is false.
