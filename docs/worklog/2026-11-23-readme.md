# README front page

## What
- Centred header: Manta's mark (new `docs/images/logo-dark.svg` / `logo-light.svg`, picked by
  GitHub's theme through `<picture>`), name, tagline, and Live site · Docs · License links.
- Six badges, all real: CI, MIT, Go 1.27, Python 3.13, Next.js 16, built on NautilusTrader.
- Hero screenshot of the terminal under the intro; screener and distributions side by side
  after "What it does". Screenshots are of the live site, 2026-11-23, quantized to 256 colours
  (terminal 266 → 118 KB, screener 129 → 52 KB, distributions 111 → 48 KB).
- Feature list, build diagram, folder table, run-it-locally and docs sections kept as they were.

## Why
The repo is public and MIT-licensed, so the README is the project's front page. It was text only.

## Decisions
- Mark only, with the name as a real heading, rather than the og-image banner: the banner is a
  fixed raster with its own copy, and SVG text would render in a fallback font on GitHub.
- Logo paths copied from `site/app/icon.svg` so the mark matches the site exactly.
- Event-response pages are not listed: they are not deployed yet.
- Existing sections were already accurate and short; checked routes, versions and env examples
  against the code rather than rewriting them.
